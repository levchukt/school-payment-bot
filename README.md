# NEUTRON · бот обліку оплачених уроків

Telegram-бот для власника школи: оплати, списання уроків, відвідуваність груп, баланси.

## Запуск

```
pip install -r requirements.txt
python bot.py
```

Змінні середовища (файл `.env` або налаштування хостингу):

| Змінна | Обов'язкова | Що це |
| --- | --- | --- |
| `BOT_TOKEN` | так | токен бота від @BotFather |
| `DB_PATH` | ні | шлях до файлу бази. Без неї — `data/school_bot.db` |
| `ADMIN_IDS` | ні | Telegram ID, яким дозволено користуватись ботом, через кому |

## Доступ

Бот приватний. Без `ADMIN_IDS` власником вважається чат, збережений у базі
(`admin_chat_id` — той, хто останнім натискав /start у старій версії).
Усі інші отримують відмову і бачать свій Telegram ID.
Якщо бот не пускає тебе самого — додай `ADMIN_IDS=<твій ID>` і перезапусти.

## База даних і оновлення

- Схема змінюється лише додаванням: нові таблиці, нові колонки, індекси.
  Існуючі дані не видаляються і не переписуються.
- Перед першою зміною схеми бот сам робить копію в `backups/` поруч із базою.
- Раз на тиждень бот надсилає файл бази в чат власника (вимикається в «Налаштуваннях»).
- Скасування заняття або оплати нічого не видаляє: запис лишається з позначкою.

Відновлення з бекапу: зупинити бота, замінити файл бази файлом бекапу, запустити.

## Як рахується групове заняття

Урок списується з усіх активних учнів групи — і з присутніх, і з відсутніх.
Відмітка «був / не був» зберігається окремо й на баланс не впливає.

За замовчуванням усі позначені присутніми і ти знімаєш відсутніх.
Щоб було навпаки — `DEFAULT_ALL_PRESENT = False` на початку `bot.py`.

## Структура

```
bot.py                екрани, кнопки, фонові задачі

database/students.py  учні
database/groups.py    групи
database/lessons.py   уроки та відвідуваність
database/payments.py  оплати, баланси, місячний звіт
database/settings.py  налаштування
```
